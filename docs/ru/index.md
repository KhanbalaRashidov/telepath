# Telepath — Документация

Telepath — это self-hosted мост, который позволяет отправлять задачи по программированию
из Telegram коding-агенту, работающему на вашей собственной машине, и в реальном времени
передаёт обратно прогресс агента: что он делает, какие файлы редактирует, какие команды
запускает, запросы на подтверждение и итоговую сводку с полным git diff. Он
**агент-независимый** (Claude Code, Gemini CLI, OpenAI Codex CLI, Aider за одним
интерфейсом) и даёт каждой задаче собственную **git-ветку**, с опциональными
**подтверждениями** в реальном времени из Telegram.

## Главное, что нужно помнить

**Telepath никогда не делает push, никогда не делает merge и никогда не трогает `main`/`master` или
удалённый репозиторий.** Худшее, что может сделать задача, — оставить проверяемую локальную
ветку, которую вы сами смержите и отправите.
