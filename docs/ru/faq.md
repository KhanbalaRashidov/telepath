# FAQ

**Какие операционные системы поддерживаются?**
Windows, Linux и macOS нативно (одна кодовая база, чистый Go, CGO отключён), а также
как Docker-контейнер.

**Telepath коммитит или отправляет мой код?**
Он коммитит в **ветку задачи** (когда `BRANCH_COMMIT=true`), но он **никогда не делает push, merge и
не трогает `main`/`master` или удалённый репозиторий**. Проверяете и делаете merge/push
вы сами. При `BRANCH_MODE=off` он даже не коммитит.

**Какие агенты поддерживают подтверждение в реальном времени?**
Только **Claude Code** (через его инструмент MCP permission-prompt). Для gemini, codex и
aider `interactive` автоматически переключается на `allowlist`.

**Работает ли это со Slack или только с Telegram?**
Оба варианта. Установите `TRANSPORT=slack` (или `both`) и укажите токены `xoxb-`/`xapp-`.
Запускайте задачи, упоминая бота, написав ему в личные сообщения или используя `/telepath …`.
См. [Транспорты](transports.md).

**Можно ли запускать несколько задач одновременно?**
Нет. Все диалоги (чаты Telegram и каналы Slack) используют один рабочий каталог `PROJECTS_DIR`,
поэтому задачи **выполняются последовательно** — по одной за раз в целом, по одной на диалог.
См. [Устранение неполадок](troubleshooting.md).

**Работает ли это за NAT / без публичного IP?**
Да. Telegram использует **long-polling**, а Slack — **Socket Mode**; оба работают только
по исходящим соединениям, поэтому не нужны webhook, входящий порт или публичный IP.

**Куда попадают API-ключи моих агентов?**
Они остаются у CLI агентов на вашем хосте и настраиваются по документации каждого
агента. Telepath хранит только токен Telegram-бота и allowlist чатов. См.
[Безопасность](security.md).

**Можно ли переключать агентов или режимы для каждого чата?**
Да — `/use <agent>`, `/perm <mode>`, `/branch <mode>` применяются к этому чату и
сохраняются до перезапуска процесса.

**Как добавить другого агента?**
Реализуйте интерфейс `Agent` в новом пакете и зарегистрируйте его одной строкой.
См. [Добавление агента](adding-an-agent.md).

**Как добавить язык документации?**
Скопируйте `docs/en/` в `docs/<locale>/`, переведите текст и зарегистрируйте локаль
в `mkdocs.yml` и в ссылках переключателя языка. См.
[CONTRIBUTING.md](../../CONTRIBUTING.md#adding-a-documentation-language).

**Как обновить Telepath?**
Скачайте последний бинарный файл со страницы Releases или пересоберите из исходников
(`go install …@latest` или `make build`). Конфигурация и `.env` не меняются.

**Какова стоимость?**
Telepath бесплатен (MIT). Вы платите только за использование базового агента/модели
по вашим собственным аккаунтам агентов.
