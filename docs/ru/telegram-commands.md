# Команды Telegram

Все команды и кнопки работают только в чатах, перечисленных в `ALLOWED_CHAT_IDS`.
Настройки, изменённые через `/use`, `/perm` и `/branch`, действуют **для каждого чата отдельно**.

## Команды

| Команда | Синтаксис | Пример | Действие |
|---------|-----------|--------|----------|
| `/help` | `/help` | `/help` | Показать список команд. |
| `/agents` | `/agents` | `/agents` | Показать настроенных агентов с их статусом установки и возможностями (потоковая передача, resume, интерактивное подтверждение, события редактирования файлов). |
| `/use` | `/use <agent>` | `/use gemini` | Установить агента по умолчанию для этого чата. |
| `/perm` | `/perm <mode>` | `/perm interactive` | Установить режим разрешений для этого чата: `auto`, `allowlist` или `interactive`. |
| `/branch` | `/branch <mode>` | `/branch per-task` | Установить режим веток для этого чата: `off` или `per-task`. |
| `/<agent>` | `/<agent> <task>` | `/claude fix the null check in parser.go` | Запустить задачу с конкретным агентом, игнорируя агента чата по умолчанию только для этой задачи. |
| *(обычное сообщение)* | `<task text>` | `add retry logic to the HTTP client` | Запустить задачу агентом чата по умолчанию. |
| `/resume` | `/resume <text>` | `/resume now add a test for it` | Продолжить последнюю сессию в этом чате (только Claude). |
| `/branches` | `/branches` | `/branches` | Показать существующие ветки `telepath/*` в `PROJECTS_DIR`. |
| `/status` | `/status` | `/status` | Показать текущие режимы агента/разрешений/веток и выполняется ли задача. |
| `/cancel` | `/cancel` | `/cancel` | Отменить выполняемую задачу. Telepath отменяет контекст и убивает дерево процессов агента. |

Примечания:

- Команда может быть адресована боту по имени (например, `/claude@MyBot …`); суффикс `@name`
  отбрасывается.
- В каждом чате одновременно выполняется **только одна задача**, а поскольку все чаты используют
  одно рабочее дерево, задачи **выполняются последовательно глобально**. Если рабочее
  пространство занято, вы получите короткий ответ с просьбой повторить попытку позже.
- `/resume` работает только с агентами, которые поддерживают возможность resume, — сейчас это
  **Claude**. Команда выполняется в режиме разрешений `auto`, а директория проекта восстанавливается
  из карты в памяти, которая теряется при перезапуске Telepath.

## Команды Slack

В Slack каждая команда выше является подкомандой единственной slash-команды `/telepath`,
а задачи запускаются упоминанием бота или личным сообщением. Соответствие
1:1 с Telegram:

| Telegram | Slack |
|----------|-------|
| `/help` | `/telepath help` |
| `/agents` | `/telepath agents` |
| `/use <agent>` | `/telepath use <agent>` |
| `/perm <mode>` | `/telepath perm <mode>` |
| `/branch <mode>` | `/telepath branch <mode>` |
| `/branches` | `/telepath branches` |
| `/status` | `/telepath status` |
| `/cancel` | `/telepath cancel` |
| `/resume <text>` | `/telepath resume <text>` |
| `/<agent> <task>` | `/telepath <agent> <task>` или `@Telepath <agent>: <task>` |
| *(обычное сообщение)* | `@Telepath <task>` или личное сообщение |

Примечания:

- Подкоманда `/telepath`, которая не является известной командой или именем агента, рассматривается
  как задача агента по умолчанию (например, `/telepath fix the flaky test`).
- Вывод задачи публикуется в **треде** под сообщением-триггером (или под первым ответом бота
  для slash-команд). Живое статус-сообщение редактируется на месте точно так же, как в Telegram.
- Кто может пользоваться ботом, определяется `ALLOWED_SLACK_USER_IDS` /
  `ALLOWED_SLACK_CHANNEL_IDS` (см. [Безопасность](security.md)).

## Inline-кнопки

Кнопки ниже работают в обоих транспортах (inline-клавиатуры Telegram, Block Kit в Slack).

### Подтверждение (интерактивный режим)

Когда задача выполняется в режиме `interactive` с Claude, каждое контролируемое действие
появляется как сообщение с двумя кнопками:

- **✅ Approve** — разрешить действие; агент продолжает работу.
- **⛔ Deny** — отклонить действие; агенту сообщается, что оно отклонено.

Если никто не ответит в течение `APPROVAL_TIMEOUT_SECONDS`, запрос **автоматически
отклоняется**. См. [Разрешения](permissions.md).

### После задачи (режим веток per-task)

Когда задача завершается (или падает) в ветке задачи, Telepath предлагает:

- **🌿 Keep branch** — оставить ветку, чтобы вы проверили её, смержили и отправили
  сами.
- **🗑 Delete branch & restore base** — удалить ветку задачи и вернуть на базовую ветку.

## Живое статус-сообщение

Во время выполнения Telepath поддерживает **одно статус-сообщение**, которое редактирует
на месте, например:

```
🤖 claude · 🌿 telepath/fix-null-… · ✏️ parser.go · ▶ go build ./... · ✅ committed a1b2c3d
```

Редактирование ограничено по частоте, поэтому сообщение обновляется примерно раз в секунду,
а не на каждый токен. Каждое редактирование файла также отправляется отдельным сообщением
с unified diff (или, если он слишком большой для Telegram, как документ `.diff`).
